# UX Copy Skill (design:ux-copy)

Write and review microcopy, labels, error messages, and UI text for this project.

## Primary Language

**Hebrew** — all user-facing copy defaults to Hebrew unless a specific component targets another language.

## Copy Principles

- **Clarity over cleverness:** Plain language, short sentences
- **Action-oriented labels:** Buttons say what happens ("שלח תרומה", not "אישור")
- **Specific errors:** Tell users what went wrong and how to fix it
- **Consistent terminology:** Use the same word for the same concept everywhere

## Hebrew Writing Guidelines

- Use formal but warm tone (לשון נקבה/זכר matched to context)
- Avoid passive voice when active is possible
- Numbers: use Western numerals (1, 2, 3) unless specifically stylistic
- Currency: ₪ before the amount (₪100) or "ש״ח" after (100 ש״ח) — pick one and be consistent

## Copy Patterns

**Buttons:**
- Primary action: verb + noun ("בחר סכום", "שלח", "המשך")
- Destructive: clear and direct ("מחק", "בטל הזמנה")
- Cancel: "ביטול" (not "לא")

**Empty states:**
- Explain what's missing + invite action ("עדיין אין תרומות. התחל עכשיו.")

**Error messages:**
- What happened + how to fix ("הסכום חייב להיות לפחות ₪10. נסה שוב.")

**Loading states:**
- Active verb ("טוען...", "שולח...")

## When Invoked

- Write new UI copy from a description or wireframe
- Review existing copy for clarity, tone, and consistency
- Translate copy between Hebrew and English while preserving intent
- Audit all labels and messages for consistency
